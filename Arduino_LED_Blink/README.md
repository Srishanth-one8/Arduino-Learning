# Arduino LED Blink

## Project Overview
This is my first Embedded Systems project using Arduino Uno. The project demonstrates how to control LEDs using Arduino programming.

## Components Used
- Arduino Uno
- Breadboard
- 3 LEDs (Red, Green, Yellow)
- 3 × 220Ω Resistors
- Jumper Wires

## Software Used
- Tinkercad
- Arduino C Programming
- Visual Studio Code

## Circuit
The Arduino Uno is connected to three LEDs through current-limiting resistors. The LEDs are connected to digital pins and blink together every 500 milliseconds.

## Program Features
- Configure LED pins as OUTPUT
- Turn all LEDs ON
- Wait for 500 ms
- Turn all LEDs OFF
- Repeat continuously

## Learning Outcomes
- Understanding `setup()` and `loop()`
- Using `pinMode()`
- Using `digitalWrite()`
- Using `delay()`
- Basic GPIO programming
